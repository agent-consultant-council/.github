# Support

Thank you for using Agent Consultant Council.

## Getting Help

Before requesting support:

1. Read the repository README.
2. Review the available documentation.
3. Search existing GitHub Issues.
4. Check whether the problem has already been reported.

## Bug Reports

* Use GitHub Issues and select the **Bug Report** template.
* Include relevant versions, error messages, and reproduction steps.
* **Never include API keys, passwords, private tokens, or sensitive user information.**

## Feature Requests

* Use the **Feature Request** issue template.
* For significant architectural proposals, discuss the approach before implementation.

## Questions and Discussions

* Use **GitHub Discussions** when enabled by the repository maintainers.

## Security Issues

* Do not report security vulnerabilities through public issues. Follow the instructions in `SECURITY.md`.
