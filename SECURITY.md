# Security Policy

## Reporting a Vulnerability

We take security vulnerabilities seriously.

* **Please do not disclose vulnerabilities publicly** through GitHub Issues or Discussions.
* Use GitHub's private vulnerability reporting feature where available, or contact the repository maintainers privately.

## Scope

Security reports involving the following areas are particularly important:

* Credential and secret exposure.
* Unauthorized context or filesystem access.
* Sensitive information leakage.
* Provider communication and data transmission.
* Authentication and authorization.
* MCP security.
* Browser automation and session isolation.
* Configuration and policy bypasses.
* Usage and budget enforcement bypasses.
* Plugin and hook execution security.

## Responsible Disclosure

Please provide:

* A description of the vulnerability.
* Its potential impact.
* Affected components and versions.
* Reproduction information where safe.
* Suggested mitigations, if available.

*(Please avoid accessing, modifying, or disclosing other users' data while investigating vulnerabilities.)*

## Security Updates

Security fixes and relevant advisories will be communicated through the affected repositories.
